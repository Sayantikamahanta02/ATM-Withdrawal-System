# ATM Withdrawal System

A simple Python project that simulates an ATM withdrawal process.

## Features

- Checks account balance
- Verifies ATM PIN
- Withdraws money
- Displays remaining balance
- Handles invalid PIN
- Handles insufficient balance

## Requirements

- Python 3.x

## How to Run

1. Download or clone this repository.

```bash
git clone https://github.com/YourUsername/ATM-Withdrawal-System.git
```

2. Open the project folder.

3. Run the program.

```bash
python atm.py
```
